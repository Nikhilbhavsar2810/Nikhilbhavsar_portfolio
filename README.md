# Nikhil Bhavsar Portfolio

A cinematic, responsive portfolio built with Next.js, TypeScript, Framer Motion, and Lenis.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Customise content

- Projects: `data/projects.ts`
- Skills: `data/skills.ts`
- Experience: `data/experience.ts`
- Contact links: `components/sections/Contact.tsx`
